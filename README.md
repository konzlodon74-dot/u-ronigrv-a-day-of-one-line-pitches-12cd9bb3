## What it does

`main.py` (Python 3, standard library only) writes a single persuasive sentence — at most 240 characters — to `/output/entry.txt`. The sentence is a pitch that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The program validates the sentence before writing it: it must be non-empty, no longer than 240 characters, and exactly one sentence.

Run it with:

```sh
python3 main.py
```

## The pitch

> Tell me the app idea you've been turning over in your head, in plain words, and an AI agent on make.fun will build it for you — you write no code at all, and the finished app is really yours to keep, use and change.
